# ARTEFACT — веб-приложение для коллекционирования и обмена цифровыми активами

Дипломный проект. Полнофункциональный прототип платформы, на которой пользователи
создают уникальные цифровые активы, коллекционируют их, продают за внутреннюю валюту
и обмениваются друг с другом напрямую (P2P).

---

## ✨ Возможности

- **Регистрация и авторизация** — JWT-токены, пароли хешируются через bcrypt.
- **Кошелёк** — у каждого пользователя баланс внутренней валюты (◈ токены); курс **1 токен = 1 рубль**.
- **Пополнение баланса** — три способа: Карта РФ, QR-код (шаблонный), номер телефона. Бета-режим для презентации.
- **Вывод средств** — три способа: Карта РФ, Криптовалюта, P2P. Сумма списывается с баланса мгновенно.
- **Перевод токенов** — мгновенный перевод другому пользователю по нику.
- **Витрина (маркетплейс)** — поиск, фильтры по категории и редкости, сортировка, фильтр «только в продаже».
- **Создание («минт») активов** — каждому активу генерируется уникальная **процедурная обложка** (детерминированный SVG по числовому семени) и случайная редкость.
- **Покупка** активов за токены с автоматическим переводом средств между пользователями.
- **P2P-обмен** — бартерные предложения «мой актив ⇄ ваш актив» с подтверждением второй стороной.
- **Профиль и коллекция** — статистика, оценочная стоимость коллекции.
- **Рейтинг коллекционеров** и **лента активности** в реальном времени.
- **Служба поддержки** — пользователи пишут обращения, администратор отвечает.
- **Панель администратора** (`#/admin`) — просмотр всех тикетов, ответы, закрытие обращений.
- Адаптивный интерфейс (десктоп / планшет / мобильный).

## 🛠️ Технологии

| Слой        | Технологии                                  |
|-------------|---------------------------------------------|
| Backend     | Node.js, Express                            |
| Авторизация | jsonwebtoken (JWT), bcryptjs                 |
| Frontend    | HTML, CSS, чистый JavaScript (SPA)          |
| Графика     | Процедурная генерация SVG (без внешних файлов) |
| Хранилище   | In-memory + автосохранение в `data.json`    |

> Данные хранятся в памяти и дублируются в файл `data.json`, поэтому переживают
> перезапуск при локальной разработке. Для продакшена слой хранения легко заменить
> на полноценную БД (PostgreSQL, MongoDB) — это вынесено в раздел «дальнейшее развитие».

## 🚀 Запуск локально (в Visual Studio Code)

1. Установите [Node.js](https://nodejs.org/) (версия 18 или новее).
2. Откройте папку проекта в VS Code: **File → Open Folder → выбрать папку `sosed`**.
3. Откройте терминал в VS Code (**Terminal → New Terminal**) и выполните:

   ```bash
   npm install
   npm start
   ```

4. Откройте в браузере **http://localhost:3000**

Для разработки с автоперезапуском при изменениях:

```bash
npm run dev
```

## ☁️ Развёртывание на Railway.app

Самый простой способ опубликовать сайт в интернете.

1. Зайдите на **[railway.app](https://railway.app)** → **Sign Up** через GitHub
   (нужен аккаунт на [github.com](https://github.com) — создайте, если нет, это бесплатно).

2. Загрузите проект на GitHub:
   - Зайдите на github.com → **New repository** → назовите `sosed` → **Create repository**.
   - На странице репозитория нажмите **uploading an existing file**.
   - Перетащите **все файлы из папки `sosed`** (важно: содержимое папки, а не саму папку).
   - Нажмите **Commit changes**.

3. В Railway: **New Project → Deploy from GitHub repo → выберите `sosed`**.

4. Railway сам определит проект на Node.js, выполнит `npm install` и запустит `npm start`.
   Через минуту в разделе **Settings → Networking → Generate Domain** появится
   публичная ссылка вида `sosed.up.railway.app`.

> Порт назначается автоматически через переменную окружения `PORT` — приложение
> уже это учитывает, дополнительная настройка не требуется.

### Необязательные переменные окружения

| Переменная   | Назначение                              | По умолчанию                  |
|--------------|-----------------------------------------|-------------------------------|
| `PORT`       | Порт сервера (задаёт Railway сам)        | `3000`                        |
| `JWT_SECRET` | Секрет для подписи токенов               | значение по умолчанию (смените на проде) |

На Railway файловая система контейнера временная, поэтому `data.json` сбрасывается
при передеплое — демо-данные при этом создаются заново автоматически.

## 🔌 Основные эндпоинты API

```
POST /api/register            регистрация
POST /api/login               вход
GET  /api/me                  текущий пользователь
GET  /api/assets              список активов (фильтры, поиск, сортировка)
GET  /api/assets/:id          карточка актива + история
POST /api/assets              создать (минт) актив
POST /api/assets/:id/buy      купить
POST /api/assets/:id/list     выставить на продажу
POST /api/assets/:id/like     лайк
POST /api/trades              предложить обмен
POST /api/trades/:id/accept   принять обмен
GET  /api/leaderboard         рейтинг коллекционеров
GET  /api/activity            лента активности
```
